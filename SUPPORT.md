# Support

- **Questions and usage help:** open a discussion in GitHub Discussions.
- **Bug reports:** open an issue using the bug report template.
- **Feature and provider requests:** open an issue using the feature or provider
  request template.
- **Security vulnerabilities:** follow [SECURITY.md](SECURITY.md) and report
  privately. Do not open a public issue.
- **Documentation:** see [README.md](README.md) and [docs/](docs/).

This is a community project and does not provide a commercial support SLA.
